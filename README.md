# 💻 Portfólio | Andressa Santos

Portfólio pessoal desenvolvido para apresentar meus projetos, habilidades técnicas e trajetória na área de tecnologia.

O objetivo é reunir meus trabalhos em uma interface moderna, interativa e responsiva, demonstrando meus conhecimentos em **desenvolvimento Front-End**.

## 🌐 Acesse o portfólio

**[Visualizar portfólio online](https://andressa-santoss.github.io/)**

## ✨ Funcionalidades

- **Design responsivo:** interface adaptada para desktop, tablet e dispositivos móveis.
- **Animação de digitação:** alternância dinâmica entre os textos `FRONT-END` e `FREELANCE`.
- **Navegação por seções:** acesso rápido às diferentes áreas do portfólio.
- **Skills:** apresentação visual das tecnologias e ferramentas.
- **Formação acadêmica:** informações sobre minha trajetória educacional.
- **Experiência profissional:** carrossel de empresas.
- **Projetos:** cards com imagens, descrições, tecnologias e links para visualização.
- **Efeitos interativos:** animações hover, transições e imagens que recuperam suas cores ao passar o mouse.
- **Download do currículo:** acesso ao currículo em PDF.
- **Contato:** direcionamento para meu perfil profissional no LinkedIn.

## 💻 Como executar localmente

1. Clone o repositório do portfólio.
2. Abra a pasta do projeto no Visual Studio Code.
3. Instale a extensão **Live Server**, caso ainda não tenha.
4. Clique com o botão direito no arquivo `index.html`.
5. Selecione **Open with Live Server**.

O projeto será aberto no navegador para visualização e desenvolvimento.

## 📱 Responsividade

O portfólio foi desenvolvido com atenção à experiência em diferentes tamanhos de tela, utilizando CSS Grid, Flexbox e Media Queries.

A interface adapta a disposição dos cards, títulos, imagens, botões e demais elementos para facilitar a navegação em dispositivos móveis.
